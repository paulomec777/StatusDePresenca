# Status de Presença

Painel para exibir em uma TV ou monitor da seção, mostrando se a chefia está
presente e trazendo avisos, aniversariantes do dia e feriados do mês. Feito
para a Chefia de Suprimento.

**Veja funcionando:** https://paulomec777.github.io/StatusDePresenca/

## Funcionalidades

- **Status do chefe e do subchefe:** presente, fora da chefia, em viagem,
  almoço, férias ou reunião, cada um com sua cor.
- **Quadro de informações** editável na própria tela, salvo no navegador
  (`localStorage`).
- **Aniversariantes do dia** e **feriados do mês**, calculados pela data
  atual.
- **Plano de fundo rotativo**, que troca a cada 15 minutos.
- Layout responsivo para telas menores.

## Tecnologias

HTML, CSS e JavaScript puro, sem frameworks e sem servidor: tudo roda em um
único `index.html`.

## Como usar

1. Clone o repositório ou baixe os arquivos.
2. Abra o `index.html` no navegador.
3. Para adaptar à sua seção, edite no `index.html` as listas `aniversariantes`
   e `feriados` e os nomes dos cartões.

Os nomes no código (Gen Alfa, Cel Bravo etc.) são fictícios.
